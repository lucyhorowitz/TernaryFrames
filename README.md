# TernaryFrames

Lean 4 formalization of ternary frames and incoherence-space semantics.

## Documentation Site

This repository is configured to deploy docs to GitHub Pages from the `main`/`master` branch using:

- `.github/workflows/deploy_docs.yml`
- `leanprover-community/docgen-action`

Expected URLs after GitHub Pages is enabled:

- Homepage: `https://lucyhorowitz.github.io/TernaryFrames/`
- API docs: `https://lucyhorowitz.github.io/TernaryFrames/docs`
